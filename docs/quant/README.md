# Quant 文档索引

这个目录用于沉淀基于 `nofx` 经验发展出来的长期量化交易系统设计、研究计划、回测方案和实施记录。

## 当前文档

- [长期量化交易系统设计方案](./2026-06-14-quant-trading-system-proposal.md)：定义系统定位、目标校准、架构分层、策略设计原则、MVP 路线和 AI 辅助边界。
- [量化回测框架设计](./2026-06-14-backtest-framework-design.md)：定义可信回测的目标、数据边界、核心模型、执行假设、风控模块和 MVP 实施顺序。

## 文档分层建议

后续量化相关文档建议按以下主题放在本目录：

- `system-design`：系统架构、模块边界、数据流和执行流。
- `research`：策略假设、特征分析、市场状态研究。
- `backtest`：回测框架、数据质量、费用/滑点模型、验证报告。
- `strategies`：具体策略设计、参数版本、适用 regime 和失效条件。
- `risk`：组合风控、仓位 sizing、冷却机制、退出状态机。
- `reports`：paper trading、小资金实盘和周期性复盘报告。

## 起步顺序

1. 先建立可信回测框架。
2. 再验证第一个最小策略。
3. 然后进入 paper trading。
4. 最后才考虑小资金实盘和多策略组合。
