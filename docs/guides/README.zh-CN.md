# 使用与排障

## 日常操作

1. 先确认交易员状态、行情时间和交易所账户同步正常。
2. 在决策记录中查看 setup、周期角色、因子证据和拒绝原因。
3. 在持仓详情中核对结构止损、执行止损、目标、手续费和持仓 thesis。
4. 参数调整后确认策略版本已保存并启用。
5. 参数回放只衡量分类稳定性；盈利能力需要结合独立 setup episode 和已平仓净结果判断。

## 风险建议

- 新策略先使用模拟盘。
- 单笔风险、最大保证金使用率和最大并发仓位应同时限制。
- ATR 缓冲用于避免结构止损被正常波动扫掉，不会移动结构目标。
- 不要因为短期不开仓就直接降低所有阈值；先区分没有 setup、证据不足、风险拒绝和执行失败。
- AI 校准没有足够独立样本时拒绝生成建议是正常行为。
